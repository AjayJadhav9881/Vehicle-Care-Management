# Vehicle Care Management

An AI-powered vehicle maintenance assistant designed to help users manage their vehicles, track maintenance activities, and receive intelligent vehicle care recommendations.

## Project Structure

- **backend/** – Node.js, Express.js and PostgreSQL backend.
- **mobile/** – React Native mobile application.

## Technologies

### Mobile
- React Native
- Expo
- TypeScript

### Backend
- Node.js
- Express.js
- PostgreSQL
- Prisma ORM

## Getting Started

Clone the repository:

```bash
git clone https://github.com/AjayJadhav9881/Vehicle-Care-Management.git
```

Install backend dependencies:

```bash
cd backend
npm install
```

Install mobile dependencies:

```bash
cd ../mobile
npm install
```

Refer to the respective project folders for configuration and setup instructions.
